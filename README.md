# Urban Sync WhatsApp Bot

Professional WhatsApp Bot built using:

- Baileys
- Express.js
- Railway
- Node.js

## Features

- QR Login
- Phone Number Pairing
- Dashboard
- Auto Reply
- Website Services
- Video Editing
- Branding
- Automation
- Portfolio
- Contact

## Installation

```bash
npm install
```

Start

```bash
npm start
```

Development

```bash
npm run dev
```

## Environment

Create a `.env` file.

```
PORT=3000
BOT_NAME=Urban Sync
OWNER_NAME=Safar
OWNER_NUMBER=91XXXXXXXXXX
SESSION_NAME=urban-sync
```

## Deployment

Deploy directly to Railway.
